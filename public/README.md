# BoardRoom Online

Онлайн-прототип настольных игр: комнаты, подключение игроков, чат, синхронизация состояния и базовые игровые прототипы.

## Локальный запуск
Нужен Node.js 20+.

```bash
npm install
npm start
```

Откройте http://localhost:10000 в двух вкладках/на двух устройствах в одной сети (для локальной сети может понадобиться разрешить входящие соединения).

## Публикация
Проект можно загрузить в GitHub и подключить к Render как Node Web Service.

Build Command: `npm install`
Start Command: `npm start`

Сервис должен слушать `process.env.PORT` и `0.0.0.0` — это уже сделано в `server.js`.

## Важно
Игровые механики здесь демонстрационные. Перед публичным запуском нужно отдельно реализовать точные правила выбранных изданий и использовать только разрешённые изображения/ассеты.
